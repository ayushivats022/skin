# Ayushi — Skincare

A minimal, aesthetic skincare brand site built with plain HTML, CSS, and vanilla JS — no build step, no frameworks.

## Pages

- `index.html` — Home
- `products.html` — Product catalog
- `contact.html` — Contact form

## Features

- Clean, minimalist design with Cormorant Garamond + Jost typefaces
- Client-side shopping cart (`cart.js`) with quantity controls, persisted via `localStorage`
- Prices in INR (₹)
- Checkout composes an order email to `ayushivats022@gmail.com`

## Running locally

Just open `index.html` in a browser — no build tools or server required.
